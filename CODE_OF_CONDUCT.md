# Code of conduct

## The short version

Be decent. Assume the person on the other end is acting in good faith and has less context than
you. Disagree about code freely; don't make it about the person.

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1. In short:

- **Expected:** welcoming and respectful language, accepting constructive criticism, focusing on
  what is best for the project and its users, and showing empathy to people with different levels
  of experience.
- **Not acceptable:** harassment, insults, sexualised language or attention, personal or political
  attacks, publishing someone's private information, or sustained disruption of discussion.

## Scope

Issues, pull requests, discussions and any other project space, plus public spaces when you are
representing the project.

## Enforcement

Report a problem to the maintainer through the repository's private contact route (a GitHub
security advisory works if you want the report to stay private). Reports are handled
confidentially. Responses range from a private word to a comment being removed, up to a permanent
ban from the project's spaces, depending on severity and pattern.

Maintainers are held to the same standard. If the maintainer is the problem, say so — GitHub's
[abuse reporting](https://support.github.com/contact/report-abuse) exists for exactly that case.
